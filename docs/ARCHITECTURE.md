# Jane Verify Architecture

```text
Jane (manager)
      |
      v
JaneOS Application Registry + Capability Kernel
      |
      v
Jane Verify
  |-- Stack Detector
  |-- Validation Orchestrator
  |-- Trusted Adapters
  |-- Sandbox Runner
  |-- Code/Security Inspector
  |-- Documentation Generator
  |-- Reporting
  |-- API / CLI / Dashboard
```

Jane Verify owns software-validation domain logic. JaneOS owns cognition, memory, authority, audit, events and application discovery.
